# Hangarin: Task & To-Do Manager

## Description

Hangarin is a Django web application designed to help users organize and manage their daily tasks. It allows users to manage priorities, categorize tasks, add notes, and break larger tasks into smaller subtasks.

## Features

- Create and manage tasks
- Set task priorities
- Categorize tasks
- Track task status
- Set task deadlines
- Add notes to tasks
- Create subtasks for larger tasks
- Manage data through Django Admin
- Generate initial sample data using Faker

## Technologies Used

- Python
- Django
- SQLite
- Faker
- Git and GitHub
